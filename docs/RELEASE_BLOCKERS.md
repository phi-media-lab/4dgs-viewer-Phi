# Release blockers

This source tree is pre-release. Repository visibility does not imply that a
release has been approved.

The following gates must close before the repository becomes public:

1. Confirm ownership and contributor permission for every exported source file.
2. Select an OSI-approved code license and add `LICENSE` plus package metadata.
3. Complete `PROVENANCE.md` with a file-level human review.
4. Complete `THIRD_PARTY.md`, review the CI lockfile inventory/npm CycloneDX
   evidence, and generate a Cargo plus runtime dependency license report/SBOM.
5. Keep all FTGS++/SelfCap-derived assets, images, goldens, and receipts out of this repository unless separate written redistribution permission is obtained.
6. Run a secret scan and a private-host/path/IP scan over the complete fresh history.
7. Prove a fresh clone can build without an untracked Cargo vendor directory;
   retain a passing remapped-path scan from the official stripped release build.
8. Default the signaling server to loopback; document that public Internet and multi-tenant deployment are out of scope.
9. Pass portable source tests, WGSL validation, browser Lesson 00 smoke, and the self-hosted AMD player lane.
10. Verify the release tag points to a clean tree and reproducible synthetic artifacts.

No current real-person asset is approved for this repository. Synthetic fixtures generated by `tools/generate_synthetic_asset.py` are the only default assets.
